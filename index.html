Mac Backup Rclone

Aplicativo de uso pessoal para realizar backups automáticos de documentos de um computador Mac para o Google Drive utilizando o Rclone.

Finalidade

O aplicativo utiliza a API do Google Drive para armazenar e recuperar cópias de segurança de arquivos selecionados pelo proprietário.

Privacidade

O aplicativo é destinado ao uso pessoal. Não oferece acesso público aos documentos armazenados no Google Drive.
